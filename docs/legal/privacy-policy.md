# Политика обработки персональных данных Career Quest (шаблон)

> Черновик. Требует проверки юристом. Текст для страницы `/privacy` —
> `frontend/src/legal/texts.ts`.

## 1. Оператор и назначение системы

Оператор — [наименование, БИН, адрес] (компания-работодатель). Career Quest —
внутренняя система планирования развития сотрудников. Она не принимает кадровые
решения автоматически: повышение грейда подтверждает HR.

## 2. Обрабатываемые данные

- Профиль: ФИО, рабочая почта, роль, грейд, стаж, уровни навыков.
- История активностей: статус участия и дата.
- Учётная запись: хеш пароля (пароль не хранится), сведения о согласии, время
  входа, IP-адрес, браузер.

## 3. Правовое основание

Согласие субъекта, которое сотрудник даёт при первом входе (с указанием редакции
и времени), и трудовое законодательство Республики Казахстан. [Юристу: уточнить
перечень оснований и внутренних документов.]

## 4. Хранение и защита

- База данных и резервные копии размещаются на серверах на территории
  Республики Казахстан; копии шифруются.
- Доступ разграничен по ролям; сессии защищены httpOnly-cookie, пароли —
  алгоритмом scrypt; действия с данными записываются в журнал аудита.
- Сроки хранения: профиль и история — [срок]; журнал действий — [срок, по
  умолчанию 365 дней]; резервные копии — [срок, по умолчанию 14 дней].

## 5. Передача третьим лицам

Персональные данные не передаются третьим лицам. При включённой AI-подсказке
поставщику модели отправляются только обезличенные числовые признаки, по которым
нельзя установить личность. Сайт не загружает сторонние шрифты, скрипты и счётчики.

## 6. Права сотрудника

Знать о наличии и составе своих данных, требовать их уточнения, блокирования или
уничтожения, отозвать согласие, обжаловать действия оператора в уполномоченном
органе. Запрос направляется HR-администратору [контакт]; срок ответа — не позднее
установленного законом.
